# Step by Step — Native iOS App

A gamified fitness application that turns real-world routes into individual and group walking goals, allowing users to log activity and visualise progress on an interactive map.

## Highlights

- Supports individual, cooperative, and competitive route-based goals
- Synchronises profiles, group membership, progress, and leaderboards through Firebase
- Calculates map position from goal completion and displays live participant progress with MapKit
- Includes authentication, onboarding, activity logging, achievements, profile management, and share-code joining
- Uses observable manager objects to coordinate application state and real-time Firestore listeners

## Tech Stack

Swift, SwiftUI, MapKit, Core Location, Firebase Authentication, Cloud Firestore, Firebase Storage, and PhotosUI.
